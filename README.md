# Trajectory Solution

A responsive, original partners-page concept inspired by the structure of an enterprise technology website. Built with semantic HTML, CSS, and vanilla JavaScript, served and bundled with Vite.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```sh
npm run build
npm run preview
```

Deploy the generated `dist` directory to a static web host.

## Features and configuration

- Responsive navigation, original CSS hero artwork, and reduced-motion support.
- Partner search and expertise filters, with accessible partner-detail dialogs.
- Inquiry form with browser validation that downloads a text draft. It does **not** send, persist, or upload personal information.
- Fictional partner profiles in `src/main.js`; replace them with approved profiles before publishing.
- Page content in `index.html`, visual styles in `src/styles.css`.

No NCS copy, logos, or imagery are included. This is a frontend concept, not an affiliation claim. Before launch, replace illustrative content and connect an approved contact backend if online inquiry delivery is required.
